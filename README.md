# Plantillas de la organización

Archivos de comunidad que GitHub aplica por defecto a todos los repositorios de la organización que no definan los
suyos: la plantilla de pull request (`pull_request_template.md`). Convención: título `[CLAVE-JIRA] <repo>: <entrega>`,
historias que cierra, commits por concern, base de datos y mensajería, configuración, pruebas, despliegue y retroceso.
